# Welcome to the Vyasen Project Hub

Vyasen is an open-source education platform in early development. This hub is
the public guide to its **product direction**, **current implementation**,
**technical design**, and **community**.

## Choose a path

- **Understand the product:** read the [vision](./product/vision.md), [overview](./product/overview.md),
  and [goals and principles](./product/goals-and-principles.md).
- **Evaluate the project:** review its [scope](./product/scope-and-boundaries.md),
  [requirements](./product/initial-requirements.md), and
  [development status](./project/development-status.md).
- **Explore the code and design:** start with the
  [current architecture](./architecture/current-architecture.md). The
  [Phase 1 database design](./architecture/phase-1-database-design.md) is a
  planned design reference, not a description of the current schema.
- **Get involved:** see the [contribution guide](./community/contributing.md)
  or browse the [contributors showcase](/community/contributors).

## About status labels

This hub separates repository facts from product intent:

- **Implemented** means there is corresponding functionality in the current
  repository.
- **In progress** means work is underway; it is not a release commitment.
- **Planned** describes an agreed direction that has not been delivered.
- **Proposed** describes a design or option still requiring validation.
- **Deferred** means the decision or implementation is intentionally left for
  later.

Product reference documents describe intended behavior. They do not prove that
the corresponding workflows, security controls, or platform modules have been
implemented.
