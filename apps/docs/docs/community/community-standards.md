# Community standards

Vyasen aims to be an open, respectful, and constructive community. Participation
is governed by the repository’s published policies:

- [Code of Conduct](https://github.com/vyasen-org/vyasen/blob/develop/CODE_OF_CONDUCT.md)
- [Security Policy](https://github.com/vyasen-org/vyasen/blob/develop/SECURITY.md)

Please use the private security-reporting channel in the security policy for
suspected vulnerabilities. Do not post exploit details, credentials, or
personal data in public discussions.
